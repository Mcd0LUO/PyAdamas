## 归档规则

- 当前文档（`README.md`、`docs/*.md`）只写当前状态、当前契约、下一步。
- 完成并被新版本覆盖的逐版本记录，移到本目录，文件名带版本区间。
- 归档文件不再修改；需要更正历史事实时在文件头加注。
- 当前文档必须链接到对应归档，避免历史丢失。
