## 二、通用优化（阶段 B）

### 新增向量化能力（全部是通用判据，无基准特化）

| 能力 | 说明 |
|---|---|
| `math.sqrt` | 2-lane `sqrtsd` + 负数守卫（`ValueError` 时机不变）；sqrt 必须早于所有写（否则守卫退出会泄漏相邻 lane） |
| float `Sub` 归约 | `s -= expr` 逐位一致（`kSubsd` 先 lane0 后 lane1） |
| `coef==0` 广播装载 | 循环内不变的下标元素（`b[i*7+c]`）装一次广播两 lane |
| 重复地址 RMW | `b[const] ±= expr` 的有序合并（`t±=lane0; t±=lane1`），含「该地址只能有配对 load+累加 store 两次访问」的后置校验 |
| 散射写 `coef>1` | float：`movsd` 低 lane + `movhlps` 抽高 lane + 2 条 `movsd` |
| 跨 coef 别名 | 按 `(list,coef)` 分组判偏移差；异组发一次运行期「地址区间不相交」守卫 |
| 借用 `xmm8-15` | 只借 RA 未占用的寄存器（第一版「xmm0-7 之外都可借」产出错值，判据必须是 RA 未占用） |
| 体块上限 64→128 | nbody advance 内层 113 条 IR 才能进入分析 |

## 三、修复的 bug

### 1. float 算式就地快路径覆盖右操作数（**误编译，-O1/-O2**）

`gen_bin_fp` 的就地快路径先 `move_fp(d, 左操作数)` 再 `op 右操作数, d`，没考虑右操作数的值就住在 `d` 里。
`s = a[j] - s` 在 -O1/-O2 下得 0.0（应为 -4.0），-O0 正确。修复：加前提「装左操作数不会覆盖右操作数」，
否则落回 `xmm0` 通用路径。

### 2. `Convert` 的 `j_src` 快速路径缺 disp32 上界（**编译失败**）

`float(<大常量> + j)` 常量 ≥ 2^32 时发 `leaq 0x10000000000(j)` → 汇编器报错、整个程序编译失败。
修复：超范围常量回落到通用 VecI 折算。

### 3. `try` 体内首次赋值的 float 被装箱后未解盒（**静默错值**）

类型检查器的 try-snapshot join 把变量类型变成 `unknown`，降级期装箱（`pa_any_from_f64`），
但使用点 AST 类型仍是 float → 把装箱字当 double 打印（输出 `5.26e-310` 而非 `5.0`）。
修复：`load_typed` 在「存储 unknown / 使用具体类型」时补 coercion（float 走 `AnyToF64`），
覆盖局部槽 / 全局 / 闭包 cell / env 四条读取路径。

三个 bug 都补了回归（477 / 474 / 482）。
