## 4. 判负清单（避免下轮重试）

- **装饰器保留原签名**（0.500）：`@contextmanager`/`@singledispatch`/`@types.coroutine` 真的改变返回类型，628 口径 500 → 496；
- **`Sequence`/`Iterable` → 函数体内 `list[T]`**（fe5）：会改变降级层的容器快速路径，`sum_iter({6,7})` 输出 `0 0`（CPython 13 6）——静默错值，回退；
- **`sys.getsizeof`**（0.511）：CPython 尺寸是实现细节，我们的布局不同，给假数字更糟；
- **`random.normalvariate`/`betavariate` 逐字节**（0.511）：要复刻 Kinderman-Monahan / Marsaglia-Tsang 算法链，单独立项；
- **`json.dump`/`load`**（0.511）：`dump` 要文件 write 协议；`load` 没有 sample 参数、返回类型静态不可定；
- **`functools.total_ordering`**（0.511）：要编译期合成比较方法，弄错就是静默错比较；
- **`if xs:` 空 list 在 -O0 崩溃**（0.501）：三档 × 20+ 形状都不可复现，判负；补了全族回归 + `opt_levels` 三档。

## 6. 这一夜的方法论教训

1. **静默错值比报错危险**：多继承偏移、`Fraction+0.5`、`unknown` 下标、GC 缓存根——四处都是「不报错但结果错」。
   现在的默认是：判不准就**拒绝**（护栏），判得准才放行。
2. **先取证再动手**：`--imports` 崩溃被我先误判成栈溢出，ASan 才证明是 use-after-free；`Sequence` 映射在类型层全绿、降级层静默错值。
3. **口径要统一**：前端基线被三个代理量过三次、漂了三次，现在统一到 `tools/frontend_baseline.sh`。
4. **判负也是交付**：装饰器签名、Sequence 映射、getsizeof、random 逐字节——都写清了根因与前置条件，避免下一轮重试。
